# Philosophy Component

A lightweight quote component for Laravel applications.

This component provides a curated collection of philosophical quotes, allowing developers to retrieve random quotes, browse the available collection, and display them in different contexts.

## Installation

```bash
composer require italofantone/philosophy
```

## Usage

Display a random philosophical quote in your terminal:

```bash
php artisan philosophy
```

### Blade Directive

Display a random philosophical quote in your Blade templates:

```blade
@philosophy
```

### Functions

The component provides the following helper function:

- `quote()` or `philosophy()->quote()`: Retrieves a random philosophical quote.
